THE IDEA

A small protocol for
big parallel work.

01 / DECLARE
≡

Make intent visible.

Each agent publishes a Claim: its goal, code scope, dependencies, and expected behavior.

02 / COORDINATE
✳

Resolve overlap early.

A coordinator reviews the shared context and records decisions before agents cross paths.

03 / INTEGRATE
↗

Keep the trail intact.

Execution, handoffs, and integration remain connected to the original Claim.
